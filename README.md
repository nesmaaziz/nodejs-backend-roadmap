# Node.js Backend Roadmap 🚀

Welcome to my learning journey toward becoming a Junior Backend Developer using Node.js!

This repository documents my progress, practical exercises, mistakes, notes, and projects as I learn backend development step by step.

My goal is not just to finish courses, but to understand the concepts, write code independently, and build real projects.

## 🎯 My Goals

* Strengthen my JavaScript fundamentals.
* Learn Node.js and Express.js.
* Build RESTful APIs.
* Work with SQL databases.
* Understand authentication and backend security.
* Learn testing, Git, and deployment.
* Build projects for my portfolio.
* Prepare for Junior Backend Developer opportunities.

## 📚 How I Study

For each topic, I aim to:

1. Learn from a free learning resource.
2. Write my own notes.
3. Practice with code.
4. Solve exercises independently.
5. Document mistakes and lessons learned.
6. Build projects using what I learned.
